# T-Invest: отчёт по портфелю

Скрипт читает портфель через T-Invest API (REST) и собирает отчёт в Markdown:

- стоимость и доходность по каждому открытому счёту;
- структура по классам активов (акции, облигации, фонды, валюта);
- позиции: средняя и текущая цена, P/L, доля в портфеле;
- концентрация: топ-5 и позиции больше 10%;
- распределение по секторам;
- облигации: погашение, номинал, следующий купон, купонный доход на 12 месяцев и помесячный график выплат.

## Безопасность

- Нужен токен **только на чтение**. Скрипт берёт его из переменной окружения `TINVEST_TOKEN`, в код и в репозиторий он не попадает.
- Клиент (`client.py`) вызывает только методы из списка `READ_ONLY_METHODS`. Выставить или отменить заявку через него нельзя, даже с торговым токеном.
- Сертификаты T-Bank подписаны корневым CA Минцифры. Он лежит в `russian_trusted_root_ca.pem`, перед использованием проверяется его SHA-256 отпечаток. Проверка TLS не отключается.
- Отчёты с данными портфеля кладите в `tinvest/reports/`: папка в `.gitignore`.

## Запуск

```bash
pip install -r tinvest/requirements.txt
export TINVEST_TOKEN=...          # токен только на чтение
python tinvest/portfolio_report.py                              # в консоль
python tinvest/portfolio_report.py --out tinvest/reports/pf.md  # в файл
python tinvest/portfolio_report.py --raw tinvest/raw            # плюс сырые JSON-ответы API
python tinvest/portfolio_report.py --account <id>               # один счёт
```

## Ограничения

- Доля в портфеле считается только для позиций, цена которых в рублях.
- Купоны по плавающим облигациям, ещё не зафиксированные эмитентом, API может отдавать нулями.
- Купонный доход указан до НДФЛ.
